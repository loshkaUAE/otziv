# HyperNote (красивый блокнот для Arch/Hyprland)

Локальный блокнот на Python с тёмным минималистичным UI, живым поиском и автосохранением.

## Что умеет
- ✨ Красивый тёмный интерфейс (в стиле Hyprland).
- 🔎 Поиск по названию, содержимому и тегам.
- 💾 Автосохранение в SQLite (`notes.db`) — заметки сохраняются навсегда.
- 🏷 Теги для быстрой фильтрации.

## Запуск
```bash
python notebook_app.py
```

## Требования
- Python 3.10+
- Tkinter (обычно уже есть в системном Python)

> Для Arch Linux, если Tkinter не установлен:
> ```bash
> sudo pacman -S tk
> ```

## Файлы
- `notebook_app.py` — интерфейс приложения.
- `notebook_storage.py` — слой хранения и поиска в SQLite.
- `notes.db` — база заметок (создаётся автоматически при запуске).
